# Afrique du Sud — enrichissement transversal final

Le dossier Countries reste la source détaillée. Ce paquet ajoute des portes d'entrée cohérentes dans :

- Civilizations : Mapungubwe ;
- Figures : Mandela, Biko, Albertina Sisulu, Charlotte Maxeke, Desmond Tutu ;
- People : Khoekhoe, communautés nguni, communautés sotho-tswana ;

- Journey : Mapungubwe, esclavage du Cap, exil/résistance/retour.

Les menus sont triés selon la règle éditoriale : Figures/People/Culture alphabétiques ; Journey/Civilizations/Stories chronologiques.
