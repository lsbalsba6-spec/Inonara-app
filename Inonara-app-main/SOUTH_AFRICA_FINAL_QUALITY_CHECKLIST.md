# Checklist de validation — Afrique du Sud

## Navigation
- [ ] Toutes les grandes rubriques s’ouvrent.
- [ ] Les sous-onglets restent visibles et stables.
- [ ] Aucun onglet ne disparaît après le clic.
- [ ] Aucun écran blanc.

## Contenu
- [ ] Aucun « À compléter », « Recherche en cours » ou « À nuancer » visible.
- [ ] Les textes courts ont été remplacés par des développements.
- [ ] Les débats sont présentés comme débats.
- [ ] Les données contemporaines sont datées.

## Cartes
- [ ] La carte du pays zoome correctement.
- [ ] Les villes et capitales sont cliquables.
- [ ] Les routes migratoires affichent leurs tracés.
- [ ] Les périodes anciennes sont visibles.
- [ ] Aucun contour politique ancien n’est inventé.

## Médias
- [ ] Chaque image affiche un auteur.
- [ ] Chaque image affiche une licence.
- [ ] Chaque image possède une page source.
- [ ] Les images cassées sont retirées ou remplacées.

## Technique
- [ ] `python scripts/check_frontend_relative_imports.py` réussit.
- [ ] `python scripts/audit_south_africa_quality.py` réussit.
- [ ] `npm run build` réussit.
- [ ] Vercel est vert.
