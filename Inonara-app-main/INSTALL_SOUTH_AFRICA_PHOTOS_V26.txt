AFRIQUE DU SUD — RESTAURATION DES VRAIES PHOTOS V26

Ce pack ne remet aucune illustration SVG.
Il télécharge six vraies photographies libres depuis Wikimedia Commons,
les stocke localement dans le projet et rattache les contenus sud-africains
aux images correspondant à leur thème.

IMPORTANT
Le téléphone doit être connecté à Internet pendant l'exécution du script.

COMMANDES TERMUX

cd ~/inonara-app

unzip -o /sdcard/Download/inonara-afrique-du-sud-restauration-photos-v26.zip -d .

python scripts/apply_south_africa_photos_v26.py

python scripts/verify_south_africa_photos_v26.py

python -m py_compile   backend/data/country_dossiers/*.py   backend/data/__init__.py

cd frontend
CI=true npm run build

SI LE BUILD EST VERT

cd ~/inonara-app

git add   backend/data/country_dossiers   frontend/public/images/south-africa-v26   scripts/apply_south_africa_photos_v26.py   scripts/verify_south_africa_photos_v26.py   INSTALL_SOUTH_AFRICA_PHOTOS_V26.txt

git commit -m "fix: restaurer les vraies photographies Afrique du Sud V26"

git push

APRÈS AVOIR VÉRIFIÉ LE SITE

find backend/data/country_dossiers -type f -name '*.v26.bak' -delete
