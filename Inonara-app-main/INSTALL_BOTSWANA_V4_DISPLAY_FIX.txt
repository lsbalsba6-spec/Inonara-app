BOTSWANA V4 — CORRECTION D’AFFICHAGE

CAUSES TROUVÉES DANS TON PROJET ACTUEL

1. L’API récupère le dossier avec le code ISO2 en majuscules.
   Botswana était enregistré sous "botswana" au lieu de "BW".
   Résultat : /country-dossiers/BW renvoyait 404.

2. CountryDossierView importait SouthAfricaProvincesCities,
   mais le fichier exporte SouthAfricaDistrictsCities.
   Résultat : build React cassé.
