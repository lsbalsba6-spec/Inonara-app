AFRIQUE DU SUD — ÉCOSYSTÈME TRANSVERSAL FINAL V1

Ce ZIP enrichit les menus principaux à partir du travail déjà fait dans Countries :
- Atlas : Mapungubwe comme entité historique approximative ;
- Journey : Mapungubwe, esclavage du Cap, exil/résistance/retour ;
- Civilizations : Royaume de Mapungubwe ;
- Figures : Mandela, Biko, Albertina Sisulu, Charlotte Maxeke, Desmond Tutu ;
- People : Khoekhoe, communautés nguni, communautés sotho-tswana ;
- Culture : jazz sud-africain, isicathamiya, amapiano, izibongo, cuisines du Cap ;
- Stories : de l'apartheid à la démocratie constitutionnelle ;
- Timeline : enrichie automatiquement par les nouvelles figures datées.

Tri éditorial :
- Figures, People, Culture et Diaspora : alphabétique ;
- Journey, Civilizations et Stories : chronologique.

COMMANDES TERMUX

cd ~/inonara-app
unzip -o /sdcard/Download/inonara-afrique-du-sud-ecosysteme-final-v1.zip -d .

cd frontend
CI=true npm run build

cd ..
git add backend/data frontend/src/pages SOUTH_AFRICA_ECOSYSTEM_FINAL.md INSTALL_SOUTH_AFRICA_ECOSYSTEM_FINAL_V1.txt
git commit -m "feat: enrichir tout l'écosystème avec l'Afrique du Sud"
git push
